## Projects

### LLMs and AI agents

- [**repo-bug-hunter**](https://github.com/Manishmaurya89/repo-bug-hunter): an AI coding agent that fixes real
  GitHub issues inside a Docker sandbox. Each fix is graded by the project's hidden tests from SWE-bench
  Verified, and you can replay every run in the browser. It's on PyPI.
  *Python, Docker, LLM APIs, SWE-bench*
- [**MCP-GuardBench**](https://github.com/Manishmaurya89/mcp-guardbench): checks the MCP servers you use in
  Claude, Cursor, VS Code or Windsurf for tool poisoning and rug pulls. It also benchmarks MCP security tools
  against 11 deliberately vulnerable servers. It's on PyPI.
  *Python, MCP, Docker*

### NLP and synthetic data

- [**Synthetic Document Factory**](https://github.com/Manishmaurya89/Synthetic-Document-Factory): generates
  labelled document-layout datasets with a local LLM: PDFs, page images and exact COCO and YOLO boxes using the
  DocLayNet labels.
  *Python, Ollama, ReportLab, Matplotlib*
- [**Synthetic Data Generator**](https://github.com/Manishmaurya89/Synthetic-data-generator-): makes clean,
  deduplicated sentence datasets in 13 Indian and South Asian languages with any local LLM, and exports them
  as TXT, JSON, CSV, PDF or MP3.
  *Python, Ollama, ReportLab, gTTS*

### Computer vision

- [**Basketball Analytics**](https://github.com/Manishmaurya89/Basketball-Analytics-Estimation-Using-Object-Segmentation-):
  tracks players and the ball in game footage, splits players into teams with a zero-shot CLIP model, and
  works out possession, passes and player speed on a top-down view of the court. Built on an open-source
  project.
  *YOLO, ByteTrack, CLIP, OpenCV, PyTorch*
- [**Music Recommendation from Facial Emotion**](https://github.com/Manishmaurya89/MUSIC-RECOMMENDATION-USING-FACIAL-RECOGNITION):
  reads your emotion from the webcam with a CNN and suggests songs that match it.
  *TensorFlow/Keras, OpenCV, Streamlit*
- [**Face Direction Detection**](https://github.com/Manishmaurya89/Face-direction-detection): measures how far
  your head is turned and tilted, in the browser, from MediaPipe FaceMesh landmarks. Built on an open-source
  React demo.
  *JavaScript, React, TensorFlow.js*
